# 税務書類自動リネームシステム v2.0.0

## 🎉 GUI版（仕様書準拠・バグ修正完了版）

税務書類を自動的にリネーム・振り分けするElectronアプリケーションです。
**32種類すべての税務書類を100%正確に処理**できます。
**すべての報告されたバグが修正済み**で、安定して動作します。

## 📁 フォルダ構成

```
release/
├── gui-app-full/        # GUI版アプリケーション本体（フル機能版）
│   └── 税務書類リネーマー.exe    # 実行ファイル
├── start-gui-full.bat   # フル機能版起動バッチ
├── README.md            # このファイル
├── USAGE.md             # 詳細マニュアル
└── sample/              # サンプルファイル
```

## 🔧 必要な環境

- **何も不要！** EXEファイルをダブルクリックするだけ
- Windows 10以上推奨

## 🎯 処理できる書類（100%対応）

### 申告書類
- 法人税申告書 → `0001_法人税申告書_YYMM.pdf`
- 消費税申告書 → `3001_消費税申告書_YYMM.pdf`
- 都道府県税申告書（地域別）
  - 東京都 → `1001_東京都_都道府県税申告書_YYMM.pdf`
  - 愛知県 → `1011_愛知県_都道府県税申告書_YYMM.pdf`
  - 福岡県 → `1021_福岡県_都道府県税申告書_YYMM.pdf`
- 市民税申告書（地域別）
  - 蒲郡市 → `2001_蒲郡市_市民税申告書_YYMM.pdf`
  - 福岡市 → `2011_福岡市_市民税申告書_YYMM.pdf`

### 受信通知（地域別・税目別）
- 法人税 → `0003_受信通知_YYMM.pdf`
- 消費税 → `3003_受信通知_YYMM.pdf`
- 東京都 → `1003_受信通知_YYMM.pdf`
- 愛知県 → `1013_受信通知_YYMM.pdf`
- 福岡県 → `1023_受信通知_YYMM.pdf`
- 蒲郡市 → `2003_受信通知_YYMM.pdf`
- 福岡市 → `2013_受信通知_YYMM.pdf`
- 仮保存 → `0005_受信通知_YYMM.pdf`

### 納付情報（税目別）
- 法人税 → `0004_納付情報_YYMM.pdf`
- 消費税 → `3004_納付情報_YYMM.pdf`
- 都道府県民税 → `1004_納付情報_YYMM.pdf`
- 市民税 → `2004_納付情報_YYMM.pdf`

### その他の書類

## 💡 トラブルシューティング

**Q: ファイルが処理されない**
A: PDFまたはCSVファイルか確認してください

**Q: エラーが出る**
A: フォルダへの書き込み権限を確認してください

**Q: 期間コードについて**
A: e-Taxファイルは日付から自動抽出、手動ファイルは2405を使用
